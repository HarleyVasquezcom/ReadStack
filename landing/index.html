ReadStack

stack what you read

Save the page you are reading and its readable text into a private stack in Chrome. The stack stays in your browser: read/unread marks, search, archive, and a JSON export you own. Page text is only captured when you press the button.

Download ZIP

What it does

  • One click adds the current page — title, URL and the readable text it can read — to your stack, stored privately in chrome.storage.
  • Every item carries an unread/read state; filters for All, Unread and Archived, plus live search across titles, URLs and text.
  • Archive keeps finished items out of the way without deleting them; "Tidy archive" clears the archived stack when you are done.
  • Export JSON dumps your whole stack to a file you own and can import anywhere.
  • The stack stays capped at 200 items so chrome.storage stays light; the oldest read items are pruned first, archived items are protected.

Permissions — minimal and used

  • storage — your stack and language live only in chrome.storage.local.
  • tabs + activeTab + scripting — reading page text only for the tab you clicked on: tries a plain fetch first, and only when that fails uses Chrome's read-the-active-tab API.
  • No host permissions: no site ever gets persistent access to this extension.
Honest note: page text is captured at the moment you click the button, not continuously. When a page cannot be read (some sites block reading), ReadStack saves the title and URL only, so nothing is lost.

Install

  • Download readstack.zip and unpack it somewhere permanent.
  • Open chrome://extensions and enable Developer mode.
  • Click "Load unpacked" and pick the folder (keep the folder after loading).
  • Open the popup on any page you want to keep and click "Add this tab".
